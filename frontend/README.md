# RepoInterviewer とは？

**RepoInterviewer** は，あなたのプロジェクトのソースコードに対して「模擬面接」を行うことができる VSCode 拡張機能です。指定したファイルやフォルダに基づき，AI があなたのコードを読み取り，技術的な質問を出題します。これにより，以下のような目的で活用できます：

- 就職活動に向けた **コーディング面接の練習**
- 実装内容の **自己理解の深化**

---

## 主な特徴

- **ファイル選択機能**  
面接に使用するファイルを自由に選択可能。関係のないファイルを除外することで，質問の精度を高められます。

- **キャラクター選択**  
出題スタイルの異なる複数のキャラクターから選べます（例：優しい質問・深堀りする質問など）。

- **リアルタイム質問とフィードバック**  
質問に答えるたびに、AI がその回答に対するフィードバックを即座に返します。質問もリアルタイムに生成されるため、まるで本物の面接官と対話しているような臨場感ある体験が可能です。

- **スコアによるパフォーマンス評価**  
　各回答に対して、AIが内容や構成、論理性などを評価し、スコアを提示します。これにより、自分の強みや改善点を客観的に把握できます。

- **成果の振り返り**  
終了後には回答履歴を元にしたフィードバックが得られます。
